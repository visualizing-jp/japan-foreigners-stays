# データソース

## 出典

観光庁「宿泊旅行統計調査」。URL は `src/lib/data/sources.ts`。

- 都道府県別の外国人延べ宿泊者数は、推移表（2025年12月以前の調査分、シート「旧3-1」）の年計。2011–2025年の確定値が1枚に並ぶ。
- 施設タイプは、各年の集計結果の第4表（年計）の外国人延べ宿泊者数。全施設。
- 国籍は、各年の集計結果の参考第1表（年計）。従業者10人以上の施設だけで、全施設の数より少ない。

使わない年:

- 2007–2010年。2010年4–6月調査から従業者9人以下の施設が対象に加わったため、全年で対象が揃うのは2011年から。推移表の年計も2011年から。
- 2026年。1月調査から層化の基準が従業者数から客室数に変わっていて、年の確定値もまだない。

延べ宿泊者数は人泊。1人が1泊すると1人泊で、訪日外客数（人）とは単位が違う。

## 表の形

- 推移表の見出しは「平成23年」から「令和7年」。行は「全国」と「01北海道」のような都道府県。運輸局の行は使わない。
- 第4表は、全国の行が「令和7年 1～12月 計」。外国人延べ宿泊者数の列の右に施設タイプが並ぶ。
  2014年までは5区分（旅館、リゾートホテル、ビジネスホテル、シティホテル、会社・団体の宿泊所）。
  2015年から簡易宿所が加わり6区分。施設タイプは2015年からの表だけ使う。
- 参考第1表の国籍は年によって増える。
  - 2011–2012年: 15か国・地域とその他。アメリカ・イギリスと表記。
  - 2013年から: インドネシア、ベトナム、フィリピン。
  - 2015年から: イタリア、スペイン。表記が米国・英国になる年がある。
- 合計と内訳の差は、表の注にある不詳（国籍不詳、宿泊施設タイプ不詳）。列はないので、合計から内訳を引いて置く。
- 標準誤差率30%以上のセルには＊印が付く。印を外して、公表されている数値を使う。
- 空欄と「-」は0。

## 名前の揃え方

- アメリカは米国、イギリスは英国。
- 都道府県名は先頭の番号と空白を除く。

## パイプライン

1. `fetch` — Excel を `data/raw/` へ（追跡しない）。観光庁のサイトは User-Agent がないと 403 を返す。
2. `normalize` — 表を読み `data/normalized/tables.json` へ。各年の第4表の外国人延べ宿泊者数が、推移表の同じ年・同じ都道府県と一致しなければ止める。
3. `data` — `public/data/stays.json` へ（型は `src/lib/data/cube.ts`）。その年に列がない国籍は null。
4. `verify` — 次を確かめる
   - 年が 2011–2025 で連続している
   - 都道府県の和が全国と、10人泊単位の丸めの範囲で一致する（47県を足すと差が数百人泊まで積もる）
   - 施設タイプの和（タイプ不詳を含む）が、その行の外国人延べ宿泊者数と一致する
   - 国籍の和（国籍不詳を含む）が、参考第1表の合計と一致する
   - 国籍ごとの都道府県の和が、その国籍の全国と一致する

公表値は10人泊単位に丸めてあるため、内訳の和が合計を数十人泊まで前後する。100人泊を超えて内訳が合計を超える年は、読み違いとして止める。
